You are acting as a **principal iOS engineer, SwiftUI architect, senior mobile product designer, and AI-native application developer**.

Your task is to generate the initial **native iOS application for Empower Humanity AI**.

# 2. Replit Build Environment Limitation Is Accepted

We understand that Replit does not provide a full macOS/Xcode build environment and may not be able to compile or run an iOS application.

That is acceptable.

Do **not** refuse or redirect the project to React Native because of this limitation.

Your responsibility is to:

1. generate the full native SwiftUI source,
2. generate the Xcode project structure,
3. generate the `.xcodeproj`,
4. include source files and resources,
5. provide the resulting project as a downloadable project/repository.

We will:

```text

↓

↓

Build and test with Xcode
```

# 4. Xcode Project Reliability

Replit-generated Xcode projects sometimes contain project-file inconsistencies.

Take extra care when generating:

```text
project.pbxproj
targets
build phases
source-file references
resource references
bundle identifiers
deployment targets
asset references
Info.plist configuration
```

Avoid duplicate file references.

Avoid references to files that do not exist.

Avoid absolute filesystem paths.

Use relative project paths.

Every Swift file referenced by the Xcode project must exist.

Every asset referenced by the project must exist.

Keep the project structure relatively simple to reduce `.pbxproj` corruption risk.
